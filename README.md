# Arduino Motor Control

Biblioteca de control de hardware basada en Arduino que integra temporización de alta resolución, control de velocidad de motores DC, monitoreo de corriente mediante un sensor ACS y control de un relé.

# Características

Timer: temporizador basado en micros() para medir intervalos de tiempo y ejecutar tareas periódicas sin depender exclusivamente de delay().

Motor DC: control de velocidad mediante un valor porcentual, permitiendo establecer la potencia de operación del motor.

Sensor ACS: lectura de corriente eléctrica para monitorear el consumo del sistema.

Relé: control de encendido y apagado de una carga eléctrica mediante una salida digital.
